# コマンド仕様

お立ち台Botがサーバーに登録するスラッシュコマンドの仕様です。
コマンド定義は `src/discord/commands/register.rs`、各ハンドラは `src/discord/commands/{admin,user}/` にあります。
ルーティングは `events::interaction::handle_command` が行います。

## 共通仕様

| 項目 | 内容 |
|---|---|
| スコープ | グローバル登録（`set_global_commands`）。すべてのギルドに同じコマンドが届く |
| 利用可能な場所 | サーバー内のみ。DMでの呼び出しは `guild_id` が `None` のため無視 |
| 言語 | `language::resolve_language(state, guild_id, interaction.locale)` で解決し、応答文言の i18n に使用 |
| 権限拒否時の応答 | `ephemeral` で `MessageKey::AdminPermissionDenied` のメッセージを返す |
| ハンドラ失敗時の応答 | `tracing::error!` でログ出力し、文字列 `"Error"` を返す |

## 管理者コマンド一覧

権限要件：すべて `ADMINISTRATOR` または `MANAGE_GUILD` 権限を要求します（`check_admin_permission`）。

| コマンド | 用途 |
|---|---|
| [`/register_report_channel`](#register_report_channel) | 通報先テキストチャンネルの登録 |
| [`/register_rental_button_channel`](#register_rental_button_channel) | レンタルボタンの設置先チャンネルの登録 |
| [`/register_question_preset`](#register_question_preset) | 利用目的の質問プリセット作成・更新 |
| [`/register_room`](#register_room) | レンタル対象の部屋登録 |
| [`/delete_room`](#delete_room) | 登録済み部屋の削除 |

## 利用者コマンド一覧

| コマンド | 用途 |
|---|---|
| [`/rent`](#rent) | レンタル申請の開始 |
| [`/help`](#help) | コマンドの説明を表示 |

## `/register_report_channel`

利用目的入力タイムアウト時の通知先チャンネルを登録します。

| 項目 | 内容 |
|---|---|
| 種別 | 管理者 |
| オプション | `channel: Channel`（必須）— 通知先テキストチャンネル |
| 副作用 | `guild_master.guild_channels` に `channel_type=1` で upsert |
| 応答 | `MessageKey::AdminReportChannelRegistered`（i18n、`{ $channel }` を埋める） |

非公開チャンネルを指定する場合、Botにそのチャンネルの**閲覧権限**と**発言権限**を別途付与する必要があります（コマンド側では権限チェックしません）。

## `/register_rental_button_channel`

レンタル申請ボタンの常設先を登録します。

| 項目 | 内容 |
|---|---|
| 種別 | 管理者 |
| オプション | `channel: Channel`（必須）— ボタンを投稿するテキストチャンネル |
| 副作用 | `guild_master.guild_channels` に `channel_type=2` で upsert／指定チャンネルにレンタルボタン（`custom_id=rental_start`）を1件投稿 |
| 応答 | `MessageKey::AdminRentalButtonRegistered`（i18n） |

ボタン投稿は登録のたびに行われるため、繰り返し実行するとメッセージが増える点に注意。

## `/register_question_preset`

レンタル時にユーザーへ尋ねる質問プリセットを登録・更新します。

| 項目 | 内容 |
|---|---|
| 種別 | 管理者 |
| オプション | `name: String`（必須）／`question_1` ～ `question_10: String`（任意） |
| バリデーション | `name` 未指定 → `AdminQuestionPresetNameRequired`／`question_1`～`question_10` がすべて空 → `AdminQuestionPresetAtLeastOne` |
| 副作用 | `guild_master.rental_question_presets` に `(guild_id, name)` で upsert（同名なら上書き） |
| 応答 | `MessageKey::AdminQuestionPresetSaved` |

`question_*` は1〜10の枠で、空欄や空白のみの値はスキップされます（`question_preset::normalize_optional_text`）。
プリセットは `/register_room` の `question_preset` 引数で部屋に紐付けて使います。

## `/register_room`

レンタル対象の部屋を登録します。テキストチャンネル単体・ボイスチャンネル単体・両方のセット、いずれでも登録できます。

| 項目 | 内容 |
|---|---|
| 種別 | 管理者 |
| オプション | `text_channel: Channel`（任意）／`voice_channel: Channel`（任意）／`question_preset: String`（任意） |
| バリデーション | `text_channel` も `voice_channel` も指定されない → `AdminRoomAtLeastOne`／`question_preset` を指定したが見つからない → `AdminQuestionPresetNotFound` |
| 副作用 | `guild_master.rooms` に1件 INSERT（`is_available=true`、必要に応じて `question_preset_id` を設定） |
| 応答 | `MessageKey::AdminRoomRegistered` |

複数の部屋を登録するときはコマンドを繰り返し実行してください（`UNIQUE` 制約はないため、同一 channel_id 組み合わせを誤って二重登録しないよう注意）。

## `/delete_room`

登録済み部屋を1件削除します。

| 項目 | 内容 |
|---|---|
| 種別 | 管理者 |
| オプション | `text_channel: Channel`（任意）／`voice_channel: Channel`（任意） |
| 動作 | 指定された channel id で部屋を1件 SELECT し、見つかれば `DELETE` |
| 応答 | 削除成功 → `MessageKey::AdminRoomDeleted`／該当なし → `MessageKey::AdminRoomNotFound` |

両方未指定の場合は guild 内の最初の1件が削除対象になり得るため、削除したい部屋を識別できる引数を必ず渡すことを推奨します。

## `/rent`

利用者がレンタル申請を開始します。

| 項目 | 内容 |
|---|---|
| 種別 | 利用者 |
| オプション | なし |
| 動作 | `rental::flow::start_rental(state, guild_id, user_id, voice_channel_id=None, lang)` を呼び出す |
| 応答 | `start_rental` の戻り値で分岐（下記） |

### 応答の分岐

| 戻り値 | 応答 |
|---|---|
| `AwaitingQuestions` | 利用目的入力モーダルを返す（`InteractionResponseType::Modal`） |
| `Assigned` | 割り当て完了メッセージを ephemeral で返す（`MessageKey::BotRentalAssigned`） |
| `AlreadyRenting` | ephemeral で `MessageKey::BotRentalAlreadyRenting` |
| `NoAvailableRooms` | ephemeral で `MessageKey::BotRentalNoRooms` |

このコマンドは VC 参加トリガーと違い、`voice_channel_id` を渡さないため**空き部屋の中から先頭順で1件**を割り当てます（`facade::room::find_available_room`）。

## `/help`

Botのコマンド説明を表示します。

| 項目 | 内容 |
|---|---|
| 種別 | 利用者 |
| オプション | なし |
| 応答 | `MessageKey::HelpTitle` ／ `HelpUser` ／ `HelpAdmin` を結合した文字列 |

権限制御はないため、利用者にも管理者向けの一覧が表示されます（運用・公開ドキュメントに合わせる方針）。
