# セットアップ（Bot運用者向け）

お立ち台BotをホスティングしてDiscordサーバーで利用できるようにするための手順です。

## 前提条件

- [Docker](https://docs.docker.com/get-docker/) および [Docker Compose](https://docs.docker.com/compose/install/) がインストール済み
- [Discord Developer Portal](https://discord.com/developers/applications) へのアクセス権
- Git

## 1. Discord Botの作成

1. [Discord Developer Portal](https://discord.com/developers/applications) にアクセスし、**New Application** をクリック
2. アプリ名を入力して作成
3. 左メニューの **Bot** を選択し、**Add Bot** をクリック
4. **TOKEN** の **Reset Token** をクリックしてトークンをコピー（後で使用）
5. **Privileged Gateway Intents** で以下を有効化:
   - `SERVER MEMBERS INTENT`
   - `MESSAGE CONTENT INTENT`

## 2. リポジトリのクローン

```bash
git clone https://github.com/<your-org>/otachidai.git
cd otachidai
```

## 3. 環境変数の設定

プロジェクトルートに `.env` ファイルを作成します:

```bash
cp .env.example .env
```

`.env` を編集して以下の値を設定してください:

| 変数名 | 説明 | 例 |
|---|---|---|
| `DISCORD_TOKEN` | Discord Botのトークン | `MTExxx...` |
| `POSTGRES_USER` | PostgreSQLユーザー名 | `postgres` |
| `POSTGRES_PASSWORD` | PostgreSQLパスワード | `your_password` |
| `POSTGRES_DB` | データベース名 | `otachidai` |
| `POSTGRES_HOSTNAME` | DBホスト名 | `localhost` |
| `POSTGRES_PORT` | DBポート番号 | `5432` |

## 4. 起動

```bash
docker compose up -d
```

ログを確認して正常に起動していることを確認してください:

```bash
docker compose logs -f app
```

## 5. BotをDiscordサーバーに招待

Discord Developer Portal の **OAuth2 → URL Generator** で以下を設定してOAuth2 URLを生成します:

- **Scopes**: `bot`, `applications.commands`
- **Bot Permissions**:
  - `Send Messages`
  - `Read Message History`
  - `Manage Channels`
  - `Connect`（VCイベント利用時）

生成されたURLをブラウザで開いてサーバーに招待します。

## 6. 初期設定

サーバーへの招待後、サーバー管理者が初期設定を行います。
[サーバー管理者向け: 導入手順](../サーバー管理者向け/導入手順.md) を参照してください。
