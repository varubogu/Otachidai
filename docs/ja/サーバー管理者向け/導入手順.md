# 導入手順（サーバー管理者向け）

お立ち台BotをDiscordサーバーで利用できるようにするための初期設定手順です。

## 前提条件

- お立ち台Botがサーバーに招待済みであること
- サーバー管理者権限を持つアカウントでDiscordにログインしていること

## 初期設定の順序

以下の順で設定を行ってください。

### 1. 通報先チャンネルの登録

VC参加から10分以内に利用目的が入力されなかった場合に通知が届くチャンネルを登録します。

```
/register_report_channel <テキストチャンネルID>
```

- 管理者や運営スタッフのみが閲覧できる非公開チャンネルの指定を推奨します
- 非公開チャンネルを指定する場合は、Botにそのチャンネルの**閲覧権限**と**発言権限**を付与してください

### 2. レンタルボタン用チャンネルの登録

レンタル申請ボタンを設置するチャンネルを登録します。

```
/register_rental_button_channel <テキストチャンネルID>
```

Botが自動的にそのチャンネルにレンタルボタンを投稿します。

### 3. 部屋の登録

レンタル対象となる部屋を登録します。テキストチャンネル単体、ボイスチャンネル単体、またはセットで登録できます。

```
/register_room [テキストチャンネルID] [ボイスチャンネルID]
```

- 引数はどちらか一方のみでも可（例: VCのみの部屋）
- 両方指定すると、テキスト＋VCのセットとして登録されます
- 複数の部屋を登録する場合はコマンドを繰り返し実行してください

### 登録例

```
# テキスト+VCのセット部屋
/register_room 123456789012345678 987654321098765432

# VCのみの部屋
/register_room 987654321098765432

# テキストのみの部屋
/register_room 123456789012345678
```

## 設定の確認

`/help` コマンドで現在の設定状況や管理者向けヘルプを確認できます。
