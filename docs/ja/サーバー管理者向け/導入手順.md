# 導入手順（サーバー管理者向け）

お立ち台BotをDiscordサーバーで利用できるようにするための初期設定手順です。

## 前提条件

- お立ち台Botがサーバーに招待済みであること
- サーバー管理者権限を持つアカウントでDiscordにログインしていること

## 概要

ギルド設定（通報先チャンネル / レンタルボタンchannel / 部屋一覧 / 質問プリセット / 部屋 / グループ / ルーティング）は **単一の YAML ファイル** で一括管理します。設定の追加・変更・削除はすべて `/upload_guild_config` で行います。

## 初回セットアップ

### 1. テンプレート YAML を取得

まだ何も設定していない状態でも、空のテンプレートを取得できます:

```
/download_guild_config
```

Bot から `guild_config.yml` が ephemeral 添付で返されます。

### 2. YAML を編集

ローカルでテキストエディタを開き、必要な項目を埋めます。

```yaml
version: 1

guild:
  language: ja

channels:
  report: "111111111111111111"            # タイムアウト通知の投稿先
  rental_button: "222222222222222222"     # レンタルボタンを設置するch
  room_list: "333333333333333333"         # 部屋一覧ボードの投稿先
  rental_post_fallback:                   # ルーティング不一致時の投稿先
    channel: "444444444444444444"

question_presets:
  - name: "通常募集"
    questions:
      - text: "目的は？"
        answers: ["雑談", "作業", "イベント"]
        routing_key: true                  # 投稿先振り分けの基準

rooms:
  - voice_channel_id: "555555555555555555"
    text_channel_id: "666666666666666666"
    question_preset: "通常募集"

routing_rules:
  - preset: "通常募集"
    rules:
      - when: "雑談"
        channel: "777777777777777777"
      - when: "作業"
        channel: "888888888888888888"
```

詳細な仕様は [ギルド設定 YAML 仕様](ギルド設定YAML.md) を参照してください。

### 3. YAML をアップロード

```
/upload_guild_config file:<添付ファイル>
```

- バリデーションエラーがあれば DB は変更されず、内容が ephemeral で返されます
- 成功すれば即座に反映され、ステータスボードや投稿先などが切り替わります

### 4. 動作確認

`/list_rooms` `/list_question_presets` で登録結果を確認できます。

## 設定を変更したいとき

1. `/download_guild_config` で現状を取得
2. ローカルで編集
3. `/upload_guild_config` で再投入

**注意**: アップロード時は YAML に存在しないエンティティが削除されます。アクティブなレンタルセッションを持つ部屋が削除対象になった場合、そのセッションは強制的に終了します。
