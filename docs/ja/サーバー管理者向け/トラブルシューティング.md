# トラブルシューティング

## Botがコマンドに反応しない

**原因と対処法:**

1. **Botがオンラインか確認する**  
   サーバーのメンバーリストでBotがオンライン状態か確認してください。オフラインの場合はBot運用者にBotの再起動を依頼してください。

2. **スラッシュコマンドが表示されない**  
   Botを招待した際に `applications.commands` スコープが含まれていなかった可能性があります。Bot運用者に正しいOAuth2 URLで再招待するよう依頼してください。

3. **コマンドが反映されていない**  
   スラッシュコマンドはDiscord側でのキャッシュに時間がかかることがあります（最大1時間）。しばらく待ってから再試行してください。

---

## Botが指定チャンネルに発言できない

**原因と対処法:**

1. **チャンネルの権限を確認する**  
   Botロールに対して、該当チャンネルの以下の権限が付与されているか確認してください:
   - `メッセージを送信`
   - `メッセージ履歴を読む`
   - `埋め込みリンク`

2. **非公開チャンネルを通報先に設定している場合**  
   YAML の `channels.report` に非公開チャンネルを指定した場合、そのチャンネルへの Bot の閲覧・発言権限が必要です。

---

## レンタル申請が通らない / 部屋が割り当てられない

**原因と対処法:**

1. **部屋が登録されているか確認する**  
   `/list_rooms` で確認してください。未登録なら YAML の `rooms` セクションを記述して `/upload_guild_config` を実行します。

2. **すべての部屋が使用中**  
   登録されているすべての部屋が現在レンタル中の場合、新しい申請は受け付けられません。部屋が解放されるまでお待ちください。

3. **レンタルボタン用チャンネルが未設定**  
   YAML の `channels.rental_button` を設定し `/upload_guild_config` で投入してください。

---

## 10分タイムアウト通知が届かない

**原因と対処法:**

1. **通報先チャンネルが未設定**  
   YAML の `channels.report` が設定されているか確認してください。設定後は `/upload_guild_config` を実行します。

2. **Botがそのチャンネルに発言できない**  
   上記「Botが指定チャンネルに発言できない」を参照してください。

---

## ルーティング（利用目的の自動投稿）が機能しない

**原因と対処法:**

1. **対象プリセットに `routing_key: true` を立てた質問があるか確認**  
   ルーティングは「ルーティングキー質問の回答」を元に判定します。プリセット内に該当質問が無い場合は判定が走らず、フォールバックチャンネル（設定があれば）に投稿されます。

2. **`routing_rules` の `when` 値がドロップダウンの選択肢と一致しているか**  
   ドロップダウン質問の場合、`when` は選択肢の文字列と完全一致である必要があります。アップロード時にバリデーションエラーとして表示されますが、過去にアップロードした YAML を一度ダウンロードして確認するのも有効です。

3. **フォールバックチャンネル `channels.rental_post_fallback` を設定しているか**  
   どのルールにも一致しなかった場合、フォールバックチャンネルが無いと投稿はスキップされます（Bot のログに警告が記録されます）。

---

## それでも解決しない場合

Bot運用者またはリポジトリのIssueに問題を報告してください。報告の際は以下の情報を含めてください:

- 発生した問題の詳細
- 実行したコマンド
- エラーメッセージ（あれば）
- Botのログ（Bot運用者から提供してもらう）
