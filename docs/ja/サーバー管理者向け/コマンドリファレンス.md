# コマンドリファレンス（サーバー管理者向け）

管理者権限が必要なコマンドの一覧です。ユーザー向けコマンドは [サーバー利用者向けコマンドリファレンス](../サーバー利用者向け/コマンドリファレンス.md) を参照してください。

ギルド設定（チャンネル、質問プリセット、部屋、ルーティング）は YAML ファイルで一括管理します。個別の register / delete / set コマンドは廃止されました。設定の追加・変更・削除はすべて `/upload_guild_config` で YAML を投入する形に統一されています。

---

## `/upload_guild_config`

ギルド設定全体を YAML ファイルで一括アップロードします。**アップロードされた内容で既存設定を完全に上書き**します。

| 項目 | 内容 |
|---|---|
| 権限 | サーバー管理者 |
| 引数 | `file` … YAML 添付ファイル（必須） |

**動作の要点**

- YAML はパース → 検証 → DB 書き込みの順に処理されます。エラーがあれば DB は一切変更されません。
- YAML に含まれていない部屋・グループ・プリセット・ルーティングルール・チャンネルは削除されます。
- 削除対象の部屋でアクティブなレンタルセッションがある場合、**そのセッションは強制的に終了し、ホストに通知が送られます**。
- フォールバックチャンネルが未設定で、ルーティングルールにも一致しない場合は何も投稿されません（ログに警告のみ）。

YAML スキーマの詳細は [ギルド設定 YAML 仕様](ギルド設定YAML.md) を参照してください。

---

## `/download_guild_config`

現在のギルド設定全体を YAML ファイルとしてダウンロードします。返却はあなたにだけ表示される ephemeral 添付です。

| 項目 | 内容 |
|---|---|
| 権限 | サーバー管理者 |
| 引数 | なし |

設定を編集したい場合は、まずこのコマンドで現状を取得 → ローカルで編集 → `/upload_guild_config` で再投入してください。
