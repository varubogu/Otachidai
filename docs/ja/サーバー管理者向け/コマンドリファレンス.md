# コマンドリファレンス（サーバー管理者向け）

管理者権限が必要なコマンドの一覧です。ユーザー向けコマンドは [サーバー利用者向けコマンドリファレンス](../サーバー利用者向け/コマンドリファレンス.md) を参照してください。

---

## `/register_report_channel`

通報先チャンネルを登録します。

| 項目 | 内容 |
|---|---|
| 権限 | サーバー管理者 |
| 引数 | テキストチャンネルID（必須） |

**説明**

VC参加から10分以内に利用目的が入力されなかった場合の通知先となるチャンネルを設定します。  
非公開チャンネルを指定する場合は、Botにそのチャンネルの閲覧権限と発言権限を付与してください。

```
/register_report_channel 123456789012345678
```

---

## `/register_rental_button_channel`

レンタルボタンを設置するチャンネルを登録します。

| 項目 | 内容 |
|---|---|
| 権限 | サーバー管理者 |
| 引数 | テキストチャンネルID（必須） |

**説明**

登録後、Botが指定チャンネルにレンタル申請ボタンを自動投稿します。  
ボタンをクリックしたユーザーはレンタル申請フローを開始できます。

```
/register_rental_button_channel 123456789012345678
```

---

## `/register_room`

レンタル対象の部屋を登録します。

| 項目 | 内容 |
|---|---|
| 権限 | サーバー管理者 |
| 引数 | テキストチャンネルID（任意）、ボイスチャンネルID（任意） ※どちらか一方は必須 |

**説明**

部屋はテキストチャンネル単体、ボイスチャンネル単体、またはテキスト＋VCのセットで登録できます。  
セットで登録した場合、申請者は両チャンネルへのアクセスが許可されます。
VC単体で登録した部屋では、申請通知はVC付属のテキストチャットに投稿されます。テキスト＋VCのセットでは、申請通知は指定したテキストチャンネルに投稿されます。

```
# テキスト+VCセット
/register_room 123456789012345678 987654321098765432

# VCのみ
/register_room 987654321098765432

# テキストのみ
/register_room 123456789012345678
```

---

## `/delete_room`

登録された部屋を削除します。

| 項目 | 内容 |
|---|---|
| 権限 | サーバー管理者 |
| 引数 | テキストチャンネルID（任意）、ボイスチャンネルID（任意） ※どちらか一方は必須 |

**説明**

テキスト＋VCのセットで登録された部屋は、どちらか一方のIDを指定すればセットごと削除されます。

```
/delete_room 987654321098765432
```
