# 使い方（サーバー利用者向け）

お立ち台Botを使って部屋をレンタルする方法を説明します。

## レンタル申請の方法

レンタル申請は以下の3つの方法で開始できます:

1. **レンタルボタンをクリック** — 管理者が設定したチャンネルに投稿されているボタンを押す
2. **コマンドを実行** — `/rent` コマンドを任意のチャンネルで送信する
3. **空のVCに参加する** — 参加者のいないボイスチャンネルに入ると申請が自動的に開始される

## 申請フロー

```
1. レンタル申請を開始（ボタン / コマンド / VC参加）
        ↓
2. お立ち台Botから利用目的の入力を求められる
        ↓
3. 利用目的を入力（10分以内）
        ↓
4. 部屋が割り当てられ、チャンネルへのアクセスが許可される
        ↓
5. 部屋を利用する
        ↓
6. VCから退出する
        ↓
7. Botが部屋を解放する
```

## 申請キャンセル（利用目的の入力前にVCを退出）

利用目的の入力を求められた後、入力せずにVCから退出すると申請がキャンセルされます。

```
1. レンタル申請を開始し、利用目的の入力待ち状態になる
        ↓
2. 利用目的を入力せずにVCから退出する
        ↓
3. Botが申請をキャンセルし、部屋を即座に解放する
   （サーバー運営への通知はありません）
```

## 引き継ぎフロー

利用中（部屋主）がVCから退出したとき、VC内に他の参加者がいる場合は引き継ぎが開始されます。

```
1. 部屋主がVCから退出する
        ↓
2. Botがチャンネルに「引き継ぎ」ボタン付きのメッセージを投稿する
        ↓
3. 残っている参加者が「引き継ぐ」ボタンを押す
        ↓
4. ボタンを押した参加者が新しい部屋主になり、利用継続
```

- 他の参加者が誰もいない場合は引き継ぎは発生せず、部屋が即座に解放されます。

## 引き継ぎキャンセル（誰も承諾しない場合）

引き継ぎ待ち中に誰もボタンを押さなかった場合、タイムアウトにより部屋が自動解放されます。

```
1. 引き継ぎボタンが投稿される
        ↓
2. 誰も「引き継ぐ」ボタンを押さずに5分が経過する
        ↓
3. Botが引き継ぎをキャンセルし、部屋を自動解放する
```

## 利用目的入力のタイムアウト

VC参加から **10分以内** に利用目的の入力が完了しない場合:

- サーバー運営に通知が送られます
- VCから退出した場合は申請がキャンセルされます（運営への通知なし）
