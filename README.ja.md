# お立ち台Bot

## 目的

お立ち台Botは、サーバーに用意された部屋をレンタル申請して申請した人が中心となって利用するためのBotです。

## 機能一覧

- チャンネルレンタル
  - ユーザーはレンタル申請を行い、申請が許可されると部屋を利用できます。
  - 部屋の利用が終了したら、ユーザーは利用終了の通知を送ります。
  - お立ち台Botは部屋を解放し、次の申請者が利用できるようにします。
- 多言語対応
  - 日本語と英語に対応しています。
  - サーバーごとに言語設定が可能です。


## 導入手順（サーバー管理者向け）

1. お立ち台Botをサーバーに招待します。
2. お立ち台Botにレンタルボタン用チャンネルを１つ登録します。
3. お立ち台Botに使用可能な部屋を登録します。（ボイスチャンネル単体、テキストチャンネル単体、テキストチャンネルとボイスチャンネルのセットを任意の数登録する）

## 使い方（ユーザー向け）

1. ユーザーからレンタル申請を受け付けます（レンタルボタンを押す、コマンドを送る、参加者のいないVCに入るなど）
2. お立ち台Botはユーザーに利用目的を尋ねます。
3. ユーザーから利用目的を聞いた後、申請者に部屋の利用を許可し、用途に応じたメッセージ送信とメンションを行います。
4. 申請者は許可された部屋を利用します。
5. 利用が終了したら、申請者はお立ち台Botに利用終了の通知を送ります。
6. お立ち台Botは部屋を解放し、次の申請者が利用できるようにします。


## Botコマンド

### 通報先チャンネル登録

- コマンド: `/register_report_channel`
- 引数: テキストチャンネルID
- 説明: 通報先チャンネルを登録します。管理者権限を持つユーザーのみが使用できます。通報先チャンネルは、利用目的の入力が完了せずに10分が経過した場合の通知に利用されます。非公開チャンネルを設定する場合、Botにチャンネルの閲覧権限と発言権限を付与する必要があります。

### レンタルボタン用チャンネル登録

- コマンド: `/register_rental_button_channel`
- 引数: テキストチャンネルID
- 説明: レンタルボタン用チャンネルを登録します。管理者権限を持つユーザーのみが使用できます。

### 部屋登録

- コマンド: `/register_room`
- 引数: テキストチャンネルID、ボイスチャンネルID（どちらかは必須）
- 説明: 使用可能な部屋を登録します。管理者権限を持つユーザーのみが使用できます。部屋はボイスチャンネル単体、テキストチャンネル単体、テキストチャンネルとボイスチャンネルのセットのいずれかで登録できます。

### 部屋削除

- コマンド: `/delete_room`
- 引数: テキストチャンネルID、ボイスチャンネルID（どちらかは必須）
- 説明: 登録された部屋を削除します。管理者権限を持つユーザーのみが使用できます。セットが登録されていた場合、片方のみ指定すればセットごと削除されます。

### レンタル申請

- コマンド: `/rent`
- 説明: レンタル申請を行います。申請者は利用目的を入力する必要があります。

### ヘルプ

- コマンド: `/help`
- 説明: お立ち台Botの使い方を表示します。管理者権限を持つユーザーは、管理者向けのヘルプも表示されます。

## Botイベント

### レンタルボタンクリック

利用申請を開始します。

### VC参加

利用申請を開始します。
ただしVC参加から10分が経過するまでに利用目的の入力が完了しない場合は、運営に通知を送ります。
10分経過までに利用目的の入力が完了せず退出した場合は、利用申請をキャンセルします。（運営に通知は送りません）

### VC退出

部屋主が退出した場合、利用終了通知を送ります。
ただし部屋主が退出した時点で他の参加者が残った場合は、それに加えてその時点の参加者に引き継ぎを行うか確認をします。
引き継ぎが行われた場合は、引き継いだ参加者を新しい部屋主として設定します。
